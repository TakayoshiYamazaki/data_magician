# DataMagician
### CSV ➔ 固定長テキスト変換ツール（DataMagicライク）

本ツールは、CSVデータを任意の固定長テキストファイル（Shift-JIS / CP932、改行CRLF）に変換するための高機能汎用GUIアプリケーションです。
セゾンテクノロジーの「DataMagic」のように、利用者が用意したCSVデータの各列を出力固定長項目のどの位置に配置するかを直感的にGUI上でマッピング・データ変換・検証・出力できます。

厚生労働省の「令和8年患者調査」をはじめとする各種公式フォーマットも1フォーマット1ファイルのプリセットとして標準提供されており、独自の固定長フォーマットも簡単に作成・保存・再利用できます。

---

## 🌟 主な特徴と機能

### 1. 柔軟なフォーマット管理（1フォーマット1ファイル保存 & 最近使用順表示）
- **1フォーマット1ファイル仕様**: 各種フォーマット定義は個別のJSONファイルとして特定フォルダ（デフォルト: `formats/`）に保存・管理されます。
- **フォーマット選択**: 「フォーマット選択」ドロップダウンには、設定ファイル（`config.json`）で指定した表示件数分だけ、**最近使用した順**にフォーマットが表示されます。
- **前回フォーマットの自動復元**: 前回使用したフォーマットは設定ファイルに自動記録され、次回起動時にそのフォーマット情報を自動読み込みしてプリセットします。
- **「設定保存」と「設定読込」**:
  - 「設定保存」ボタンから、フォーマット名やファイル名を指定して特定フォルダにワンクリック保存可能。
  - 「設定読込」ボタンから、保存済みまたは外部のフォーマット定義ファイルを即座に読み込み・適用可能。

### 3. DataMagicライクな高機能マッピングエディタ
- **マッピング種別の柔軟な選択**:
  - `CSV列`: 利用者のCSVデータから特定列の値を抽出
  - `固定値（定数）`: 施設番号や調査票種別など、CSVにない定数値を指定
  - `空白`: 規定のパディング文字（スペース・ゼロ等）のみを出力
- **スマート自動マッピング機能**:
  - 「列名から推測マッピング」: CSVの列名（ヘッダー）と出力項目名を自動マッチング。
  - 「左から順に1対1マッピング」: CSV列の並び順に従って先頭から1対1で割り当て。
- **5種類のパディング埋め文字に完全対応**:
  1. `[S]右詰め・前ゼロ埋め(該当なし時はスペース埋め)`
  2. `右詰め・前ゼロ埋め(数値用)`
  3. `左詰め・全角スペース埋め(漢字・住所用)`
  4. `左詰め・半角スペース埋め(一般テキスト用)`
  5. `右詰め・半角スペース埋め`
- **多彩なデータ変換ルール**:
  - `和暦元号コード`: 西暦生年月日（例: 1955-08-23）から `1:令和`, `2:平成`, `3:昭和`, `4:大正`, `5:明治` を自動判定
  - `和暦年2桁`: 西暦日付から和暦年（01〜64）を2桁ゼロ埋めで自動計算
  - `月2桁` / `日2桁`: 日付文字列から2桁ゼロ埋めで抽出
  - `性別コード`: 「男」「男性」「M」➔ `1`、「女」「女性」「F」➔ `2` に自動変換
  - `全角変換` / `半角変換`
- **文字化け（泣き別れ）防止機構**:
  - Shift-JIS（CP932）で指定バイト数を超える際、全角文字の途中で切れて文字化けを起こさないよう安全に末尾を半角スペースに補正します。

### 4. リアルタイム・プレビュー & 検証機能
- CSVを読み込むと、現在のマッピング設定を適用した**固定長テキストのリアルタイムプレビュー（先頭5件）**を表示。
- 目盛りルーラー（10B, 20B, 30B...）とバイト数インジケーターにより、規定長と一致しているかを常時視覚的に確認できます。

## ⚙ 設定ファイル (`config.json`)
テキストエディタで直接編集可能なJSON形式です。

```json
{
  "formats_directory": "formats",
  "recent_formats_limit": 10,
  "last_used_format": "formats/hosp_in_odd.json",
  "recent_formats": [
    "formats/hosp_in_odd.json",
    "formats/hosp_in_even.json",
    "formats/hosp_out_odd.json"
  ]
}
```

- `formats_directory`: フォーマットファイルを格納する特定フォルダパス（デフォルト: `"formats"`）。
- `recent_formats_limit`: 「フォーマット選択」ドロップダウンに表示する最近使用フォーマットの最大件数。
- `last_used_format`: 前回使用したフォーマットファイルパス（次回起動時に自動プリセット）。
- `recent_formats`: 最近使用したフォーマットの履歴リスト。

## 🚀 起動方法

```bash
# 依存ライブラリの確認（fletがインストールされている環境）
python3 csv_converter.py
```

### 操作手順
1. **タブ1「入力CSV設定 & プレビュー」**:
   - 「CSVファイルを選択」をクリックしてお手元のCSVファイルを選択します。（「サンプルCSV」ですぐにお試しも可能です）
2. **トップバー**:
   - 「フォーマット選択」から適用したいフォーマットを選択します（最近使用した順に表示）。
   - 必要に応じて「設定読込」から外部のフォーマットファイルを開くこともできます。
3. **タブ2「出力項目マッピング」**:
   - 「列名から推測マッピング」や「左から順に1対1マッピング」でCSV列と出力項目をリンクします。
   - 項目名、桁数、パディング埋め文字（5種類）、変換ルールを自由に編集できます。
   - 編集した設定は「設定保存」ボタンで特定フォルダ（`formats/`）に個別ファイルとして保存できます。
4. **タブ3「固定長プレビュー & 変換実行」**:
   - リアルタイムプレビューで出力イメージを確認します。
   - 「固定長テキストファイルへ変換実行」ボタンをクリックすると、指定パスに固定長テキストが出力されます。

## 📁 ディレクトリ構成

- `csv_converter.py`: メインGUIアプリケーション (Flet)
- `converter_core.py`: 固定長変換エンジン、フォーマット管理、自動マッピング、和暦変換ロジック
- `config.json`: アプリ設定ファイル（最近使用数、前回フォーマット等）
- `formats/`: 1フォーマット1ファイルで保存されたフォーマット定義ファイル群
- `create_sample.py`: テスト用CSV生成スクリプト
- `sample_hospital_inpatient.csv`: サンプルデータCSV
